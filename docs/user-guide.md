# OPEN AIGC 使用说明

## 当前版本

当前版本是本地 Windows 桌面基线，提供创意工坊（Agent 对话 + 图片生成）、无限画布、提示词库、模型与凭据管理、资源库和备份恢复能力。

## 启动应用

开发环境启动：

```powershell
pnpm tauri dev
```

安装包版本双击启动即可。首次使用需要配置模型与凭据（见下文）。

## 创意工坊

创意工坊是主要工作区，默认进入 Agent 对话模式：

1. 在底部输入框输入创作需求（支持 `/` 插入提示词模板）
2. Agent 自动进行意图理解、步骤规划与工具调用，中间过程以步骤时间线展示
3. 生成完成后，结果卡片显示缩略图、类型、状态与创建时间，可加入项目、进入资产库或打开文件位置

对话历史与画布内容会作为上下文记忆，支持连续多轮创作。

## 无限画布

画布提供节点式创作空间：

- 工具栏可新建便签、导入图片、适应视图
- 拖拽节点调整位置，拖拽节点边缘建立连线，双击连线删除
- 双击便签编辑内容（Enter 保存 / Esc 取消），Shift+拖拽框选后 Delete 批量删除
- Agent 可以直接在画布上创建节点并自动建立语义关联
- 画布视口与节点位置自动保存

## 模型与凭据

在模型管理页配置 AI 服务：

- 添加凭据时填入 Provider、显示名、模型名与 API 密钥
- API 密钥保存在 Windows 凭据管理器中，应用数据库只保存引用键
- 模型选择器会显示账号状态；凭据异常时按提示重新登录或更换账号

## 提示词库

- 新建提示词模板，支持变量占位
- 在创意工坊输入框输入 `/` 快速检索并插入模板

## 资源库

- 导入本地素材：选择文件后自动执行完整性校验并纳入受管文件库
- 按命名空间、类型、完整性状态筛选资产
- 支持打开文件、打开所在位置与批量复检
- 创意工坊生成的结果自动归档到资源库

## 备份与恢复

- 备份页一键打包工作数据库与受管文件
- 恢复前自动校验备份与当前应用 schema 的一致性，并先创建安全备份
- 恢复成功后服务热重载，无需重启应用

## 设置

支持深色/浅色主题、界面密度与导航偏好。

## 常见问题

**生成失败怎么办？** 在步骤时间线中查看失败步骤与原因；检查模型凭据是否有效（模型选择器中的账号状态）。

**密钥安全吗？** API 密钥只写入操作系统凭据管理器，数据库和日志中不保存明文。

**备份包含什么？** SQLite 工作数据库与全部受管文件，恢复时自动校验完整性。
