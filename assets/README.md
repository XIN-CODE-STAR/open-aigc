# 仓库资产

本目录保存项目拥有的设计参考、品牌源文件、产品截图、图标和非代码源资产。

`app-icon.svg` 是 AIGC Studio 应用图标的规范源文件。Windows `.ico` 通过 `pnpm tauri icon assets/app-icon.svg` 生成，不手工编辑生成文件。

禁止提交：

- 用户生成内容、学生作品和真实教学资料。
- 运行时下载、缓存、缩略图和临时文件。
- 含凭据、个人信息或受限制许可证的素材。
- 可从构建过程稳定生成的产物。

新增第三方资产必须记录来源、许可证、作者归属、允许用途和修改情况。应用运行时的受管 Asset Library 位于用户工作空间，不属于此 Git 目录。
